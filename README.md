# أجور · Workers Ledger

تطبيق ويب مستقل لإدارة أجور العمال محليًا، بثلاث صفحات: الحساب، الإعدادات، والأرشيف. يدعم العربية والتركية والإنجليزية والوضع الفاتح والداكن ومظهر الجهاز. الواجهة مناسبة للمس والكيبورد، والمبالغ دون رمز عملة.

## التشغيل

يتطلب Node.js 24 أو أحدث، دون تنزيل مكتبات:

```sh
npm start
```

افتح `http://localhost:5173`. للاختبارات:

```sh
npm test
```

الملفات ثابتة ويمكن استضافتها عبر HTTPS، بما في ذلك تحت مسار مستودع GitHub Pages. لا يحتاج التطبيق إلى خادم بيانات أو حساب مستخدم. `server.js` مخصص للتطوير المحلي.

## قواعد الحساب

- أجر اليوم = الراتب الشهري ÷ 30.
- أجر الساعة = الراتب الشهري ÷ 300.
- المسائي = الساعات × أجر الساعة × 1.5.
- الغياب أيام كاملة، والتأخير والمسائي يقبلان الساعات العشرية.
- صافي الشهر = الراتب + المسائي − الغياب − التأخير − السلف غير المحولة − خصم الدين اليدوي.
- عرض المبالغ إلى منزلتين، وتقريب إجمالي كل بند إلى منزلتين قبل حساب الصافي.
- السلفة منفصلة عن الدين ويمكن تحويلها كليًا أو جزئيًا. التحويل يعيد المبلغ إلى مستحق الشهر ويضيفه إلى الدين مرة واحدة، ويرتبط بالسلفة الأصلية.
- رصيد الدين = الدين الافتتاحي + التحويلات + العجز المرحّل − خصم الدين من الراتب − التسديد النقدي.
- خصم الدين يدوي، لا يتجاوز الدين المتبقي أو مستحقات الراتب المتاحة. التسديد النقدي ينقص الدين فقط.
- إغلاق الشهر لجميع العمال معًا يعني دفع المستحقات الموجبة، وتحويل العجز تلقائيًا إلى الدين. مراجعة قبل التأكيد. الأشهر المغلقة لا تعدّل.
- الراتب مثبت للشهر الحالي. أي تغيير عليه يطبّق من الشهر التالي. العامل المضاف وسط الشهر يأخذ راتبًا شهريًا كاملًا؛ لا يوجد احتساب تلقائي نسبي للأيام.
- الشهر الأول هو شهر تشغيل التطبيق أول مرة. بعد الإغلاق ينتقل إلى الشهر التالي بالتسلسل، دون إغلاق تلقائي بمرور التاريخ.
- يمكن حذف حركة الشهر المفتوح لتصحيحها؛ يمنع حذف سلفة لها تحويلات أو تحويل ترتبط به تسديدات لا تسمح بإلغائه. لتعديل حركة احذفها ثم أعد إدخالها.

## الحفظ والأرشفة

IndexedDB تحفظ البيانات على الجهاز والمتصفح الحاليين. يتضمن الأرشيف كشف كل عامل وحركاته ولقطة للراتب والدين عند الإغلاق. سجل الدين مستقل ويستمر حتى لو حذف الشهر المؤرشف.

مدة الاحتفاظ بالأيام قابلة للتعديل؛ `0` يعني دائمًا. الإعداد الأولي 365 يومًا والحذف اليدوي. في الوضع التلقائي تُحذف السجلات المنتهية عند فتح التطبيق أو حفظ إعدادات الأرشيف، وليس أثناء إغلاق التطبيق. طلب التخزين الدائم يخضع لقرار المتصفح.

تصدير JSON يشمل جميع البيانات والإعدادات. الاستعادة تتحقق من بنية الملف وتطلب التأكيد قبل استبدال البيانات. احتفظ بنسخة احتياطية قبل مسح بيانات المتصفح أو الانتقال إلى جهاز أو عنوان موقع آخر. النسخ الاحتياطية غير مشفرة.

يحمي عدّاد إصدار الحفظ من الكتابة فوق تغييرات متزامنة في نافذة أخرى. عند التعارض يُحدّث العرض ويُطلب إعادة المحاولة.

## التثبيت والعمل دون إنترنت

Manifest وأيقونات PNG بحجمي 192 و512 وService Worker مرفقة. بعد أول تحميل ناجح يخزّن التطبيق ملفاته محليًا للعمل دون إنترنت. لا يستخدم خطوطًا أو مكتبات من الإنترنت.

- Chrome / Edge: استخدم زر التثبيت عند ظهوره أو قائمة المتصفح.
- iPhone / iPad: المشاركة ← إضافة إلى الشاشة الرئيسية.
- التثبيت يحتاج HTTPS أو localhost ومتصفحًا يدعم PWA. دعم التثبيت يختلف حسب المتصفح.
- التحديثات البرمجية التي تغيّر ملفات التطبيق يجب أن تغيّر اسم الكاش في `sw.js`؛ يغلق المستخدم نوافذ النسخة السابقة لتفعيل التحديث.

## الكيبورد

Tab وShift+Tab للتنقل، Enter لحفظ النماذج، Escape لإغلاق الحوار، ومفاتيح الأرقام لإدخال المبالغ والساعات. مؤشرات تركيز ظاهرة وأسماء حقول واضحة. عناصر الإدخال تستخدم كيبوردًا رقميًا على الهاتف.

## التحقق

11 اختبارًا تغطي الحساب بالساعات الكسرية، الدين اليدوي والنقدي، التحويل الجزئي، رفض تجاوز الدين، تجميد الراتب، ترحيل العجز، انتقال السنة، استقلال الدين عن حذف الأرشيف، وتصحيح الحركات.

تم التحقق من صياغة ملفات JavaScript، ونجح اختبار Chromium على مقاس هاتف للحسابات والإدخال بالكيبورد وEnter/Escape والحفظ بعد إعادة التحميل والعمل دون إنترنت وإغلاق الشهر وقراءة الأرشيف. التثبيت الفعلي على أجهزة الهاتف وسطح المكتب لم يُختبر بعد.

ملفات النشر موجودة في فرع `gh-pages`. لتفعيل GitHub Pages: Settings → Pages → Deploy from a branch → gh-pages → / (root) → Save. رابط النشر بعد تفعيله: https://moh-ac-32000-del.github.io/workers-ledger/ . تفعيل Pages عبر API رُفض بصلاحيات الاتصال الحالية (HTTP 403).

## هيكل المشروع

- `ledger.js`: القواعد الحسابية والتحويل والإغلاق.
- `storage.js`: IndexedDB والتحقق الأولي من ملف النسخة الاحتياطية.
- `app.js`: الصفحات والحوارات والتفاعل.
- `i18n.js`: النصوص باللغات الثلاث.
- `style.css`: التصميم الأزرق المتجاوب والوضعان.
- `test/ledger.test.js`: اختبارات الحساب.

المشروع جديد ومستقل؛ استُلهم تنظيم البطاقات والتنقل من settings-calculator دون نسخ مشروعه.
